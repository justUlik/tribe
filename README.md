# Предзаказ мерча DR Tribe

Лендинг предзаказа: React-страница по макету 1920 и API на Node.js + SQLite.

## Запуск

```bash
npm install
npm run dev
```

Откроется клиент на http://localhost:5173, API — на http://localhost:3002.

Прод:

```bash
npm run build
npm start
```

## Ссылка на оплату

Вставьте ссылку в `src/config.ts` — константа `PAYMENT_LINK`. Она стоит под QR-кодом в модалке («по ссылке»).

## Нагрузка ~1000 человек

- Статика и картинки отдаются отдельно от записи заказов.
- SQLite в режиме WAL, очередь записи, таймаут блокировок.
- Загрузки чеков пишутся на диск (`uploads/`), в базу попадает только имя файла.
- Лимит: 30 заказов в минуту с одного IP, файл до 12 МБ (изображение или PDF).
- HTTP keep-alive, compression, до 2000 соединений.

Заказы: `data/orders.sqlite`. Файлы оплаты: `uploads/`.
